## 🌟 Aperçu du projet

**Elisabeth Couture** est un site vitrine statique conçu pour présenter l'atelier de couture éponyme basé à Cotonou, au Bénin. Fondé en 2020 par Madame Elisabeth, l'atelier propose des créations sur mesure inspirées des tissus traditionnels béninois et des techniques artisanales locales.

Le site a pour objectifs de :
- Présenter l'histoire, les valeurs et l'équipe de l'atelier
- Mettre en valeur les services proposés
- Afficher une galerie des créations
- Permettre aux clients de prendre contact facilement

## 🛠️ Technologies utilisées

- **HTML5** — Structure sémantique des pages
- **CSS3** — Mise en page, animations et design responsive (`couture.css`)
- Aucun framework JavaScript — site entièrement en HTML/CSS natif

## 🚀 Installation et utilisation

Aucune dépendance ni installation requise. Le site est purement statique.

**Cloner le dépôt :**

```bash
git clone https://github.com/votre-utilisateur/elisabeth-couture.git
```

**Lancer le site :**

Ouvrir simplement le fichier `index.html` dans un navigateur web, ou utiliser une extension comme **Live Server** sur VS Code pour un rechargement automatique.

```bash
# Avec l'extension Live Server (VS Code)
# Clic droit sur index.html → "Open with Live Server"
```

## ✨ Fonctionnalités

- **Navigation** claire et cohérente sur toutes les pages
- **Section héro** visuelle sur chaque page avec titre et sous-titre
- **Page Accueil** : aperçu des services, mini-galerie et témoignages clients
- **Page À propos** : histoire de la fondatrice, carte des 4 valeurs (Passion, Qualité, Innovation, Respect), présentation des membres de l'équipe
- **Page Services** : 4 prestations détaillées + processus de travail en 5 étapes (Consultation → Mesures → Conception → Essayage → Livraison)
- **Page Galerie** : grille de 12 créations avec effet de survol (overlay)
- **Page Contact** : formulaire complet (nom, email, téléphone, objet, message) + informations de contact
- **Footer** commun : logo, liens de navigation, coordonnées et réseaux sociaux
